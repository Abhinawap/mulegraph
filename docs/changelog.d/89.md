### 14 Nov 2026 — One file per changelog entry (#89)
- **Changed** a PR adds its changelog entry as `docs/changelog.d/<issue>.md`, not in `docs/changelog.md`, so two parallel PRs touch different files and merge on GitHub with no rebase. The union merge of #77 applied only to local merges and rebases; GitHub's merge button ignores merge attributes, so on 13–14 Nov each of PRs #84–#88 conflicted after the one before it merged and had to be rebased, force-pushed and run through CI again. `.gitattributes` is removed. `CLAUDE.md`, the `update-docs-and-commit` skill and the SessionStart reminder point to the new place.
- **Added** `scripts/gather_changelog.py`, run at tag time: it moves every entry under `## Unreleased`, ordered by issue number with the highest first, and deletes the files (the version heading is renamed after); a file not named by its issue number is refused.
- **Tests** (`tests/test_gather_changelog.py`): two entries land under `## Unreleased` in issue order above the existing ones, and their files are gone; a file named `fix-x.md` is refused and kept.
