### 25 Nov 2026 — Worktree rule works with the harness (#94)
- **Changed** CLAUDE.md → Repository Etiquette: start a branch with `EnterWorktree` from the main checkout, then rename the branch (it comes out as `worktree-<name>`, not `feature|fix/<description>`). `git worktree add ../…` is refused inside a worktree-isolated session, and a stale worktree cannot switch to a new one, so restart from the main checkout.
- **Changed** the SessionStart stale-worktree warning says the same. `.claude/worktrees/` is gitignored and inside the main checkout, so it does not disturb other sessions' work there.
