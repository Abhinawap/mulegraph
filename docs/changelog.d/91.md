### 14 Nov 2026 — Branch guard reads the commit's own checkout (#91)
- **Fixed** `.claude/hooks/guard_main.py` read the branch of the hook's own directory, the main checkout, so it refused commits made in a worktree on a feature branch. It now reads the branch where the commit runs: the session cwd from the payload, moved by `cd <dir>` segments (also inside `( … )`) and `git -C <dir>`. Every commit in the command is checked, not only the first. A commit on `main` is still refused, in the main checkout and in a worktree on `main`, and so is one after `cd -` or a bare `cd`, where the hook cannot tell the checkout. The override the error message suggests, `MULEGRAPH_ALLOW_MAIN_COMMIT=1 git commit`, now works when written in the command.
- **Added** `tests/test_guard_main.py`: runs the hook on payloads against a temporary repository with a feature worktree and a worktree on `main`.
