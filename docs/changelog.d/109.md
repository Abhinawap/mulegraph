### 26 Nov 2026 — One OpenMP thread per xdist worker; `-n 3` documented for the unit suite (#109)
- **Changed** the root `conftest.py`: under xdist, each worker sets `OMP_NUM_THREADS=1` unless the shell already set it. Previously each worker's XGBoost/BLAS opened one thread per core, and `pytest -m "not integrity" -n 3` took 7m59s on the laptop. With the pin it is about 37 s. Without `-n` (CI's `check` job), tests still run multi-threaded.
- **Changed** `CLAUDE.md` → Commands and `.claude/agents/implementer.md`: the unit-suite commands run with `-n 3`.
